# 도토리 펑 (Acorn Pop)

다람쥐 **도담**이 도토리 폭탄으로 덤불 미로를 뚫고, 다섯 고장의 대장을 물리쳐 숲의 씨앗을 되찾는 칸 단위 폭탄 미로 게임입니다. 의존성 없는 정적 웹앱(Canvas 2D)입니다.

- 판 35개: 월드 5개(도토리 숲·안개 늪·수정 동굴·눈꽃 고개·잿빛 화산) × 일반 6판 + 대장 1판
- 도토리는 2.4초 뒤 십자로 터지고, 바위는 막고 덤불은 부서지며, 다른 도토리에 닿으면 연쇄로 터집니다
- 아이템: 불씨(불꽃 길이), 도토리 주머니(동시에 놓는 수), 바람 깃털(걸음), 잎사귀 방패, 모래시계
- 적 6종(솔방울이·통통개구리·안개불·여우불·꾀돌이 두더지·돌껍질 거북)과 대장 5종이 저마다 다르게 움직입니다
- 같은 화면 대전: 사람 2명, 또는 사람 대 컴퓨터(실력 4단계), 컴퓨터를 더해 최대 4명. 1분 남으면 바위가 조여 옵니다
- 키보드(두 사람), 터치(방향 패드·도토리 단추), 게임패드(1·2번)
- 진행·최고 점수·설정은 이 기기의 localStorage 에 저장합니다

## 실행

```sh
npm run serve      # http://127.0.0.1:8650/
npm run build      # dist/ 로 복사하고 모듈·경로 검사
```

## 시험

```sh
npm test           # 폭발 전파·연쇄·아이템·적 움직임·컴퓨터 상대·판 검사·저장·헤드리스 자동 플레이
npm run autoplay   # 판마다 자동 플레이 결과(무적·시간 제한 없음)
PLAYWRIGHT_MODULE=<playwright/index.mjs 경로> npm run test:e2e   # 헤드리스 브라우저 시험(없으면 건너뜀)
```

판 검사는 35판 모두에서 출구·적·아이템이 출발점에서 닿는 곳에 있는지 보고, 자동 플레이어가 실제 규칙(도토리로 덤불 부수기, 적·대장 쓰러뜨리기, 출구 도착)으로 모든 판을 끝까지 깨는지 확인합니다.
